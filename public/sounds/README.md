# 소리 파일 넣는 곳

이 폴더에 mp3 파일을 올리면, 장소별 배경음으로 씁니다.
어떤 파일을 어느 장소에 쓸지는 `sounds.json` 에 적습니다. (예: `{"classroom": "교실.mp3"}`)

| 이름 | 장소 |
|---|---|
| field | 운동장 (아이들 노는 소리) |
| classroom | 쉬는 시간·점심시간 교실·복도 웅성웅성 (수업 시간엔 자동으로 꺼짐) |
| teacher | 교실 (선생님 수업 목소리) |
| corridor | 복도 |
| cafe | 급식실 |
| gym | 체육관 |
| library | 도서실 |
| office | 교무실 |
| outdoor | 바깥 (새소리·바람) |
| bell | 학교 종소리 |

적히지 않은 장소는 원래 합성 소리가 그대로 나옵니다.
